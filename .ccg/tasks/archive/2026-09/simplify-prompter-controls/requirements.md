# 精简提词控制、多文稿库与 PWA

## 用户要求

- 删除“试用示例”。
- 删除开始按钮上方“3 秒倒计时，从容开始”等提示文案。
- 导入文件和设置只显示图标。
- 提词时的字号像速度一样直接调节，不再打开二级菜单。
- 用户后续确认默认不要填入示例，并要求能提前准备多份稿子、按需逐篇调出。
- 用户要求做好 PWA。

## 行为与范围

- 移除示例入口、示例载入事件和首次启动的默认示例；已有 savedText 保持原样，新设备以空白文稿开始。
- 只移除首页倒计时提示，保留设置中的倒计时选项和实际倒计时。
- 图标按钮保留清楚的无障碍名称、悬浮说明、点击区域及导入时的禁用/忙碌反馈。
- 工具栏始终展示速度和字号的减小按钮、当前数值、增大按钮。字号保持 10–100 px、每次 2 px。
- 字号即时生效，并同步设置与存储；阅读进度、计时、暂停状态保持连续。
- 删除字号面板及其专用事件、焦点、Esc 和全屏分支；Esc 直接返回编辑。
- 320px、390px、844×390 横屏和桌面可用，按钮至少 44×44 px。
- 同步使用说明、现有浏览器回归与截图脚本；不修改文档解析模块。

## 多文稿库

- 本地保存多篇文稿，提供新建、命名、搜索、列表切换、删除及撤销。
- 首页继续使用单文稿编辑器；文稿库通过明确的“文稿库”入口打开。标题可直接编辑，正文继续自动保存。
- 首次没有文稿时展示空白编辑器；保留并迁移旧 savedText，已有文稿库优先，不能每次载入重复迁移。
- 使用 IndexedDB 按篇持久化文稿和当前选择，以支持多份长稿；保留 savedText 的当前正文兼容镜像。
- 切换、新建、删除时立即保留当前编辑内容，异步导入不能串到其他文稿；撤销不能覆盖切换后的稿子。
- 读写失败不能清空旧资料或中断当前会话，明确显示未保存状态。
- 无账号、无云端服务，文稿留在当前设备。

## PWA

- 修复相对路径的 manifest、service worker 注册、应用资源缓存和更新生命周期，兼容 GitHub Pages 子目录与 localhost。
- 联网成功准备后支持离线启动、查看/编辑/切换已保存文稿、提词以及 TXT/DOCX 本地导入。
- 设置中提供可用的安装入口与 iPhone 添加到主屏幕提示，显示实际离线准备状态。
- 更新不在提词或编辑时自动刷新，也不强行激活新版本；缓存清理限定本应用。
- 直接用 file:// 打开仍可使用基本提词能力；不触发不可用的 service worker 注册。

## 验证

- JavaScript 语法检查。
- Chromium / WebKit 全部现有 UI 回归，更新旧示例与二级面板断言。
- 浏览器检查空白首屏、图标按钮、直接调节字号、边界禁用、存储同步、提词状态和进度连续性。
- 检查竖屏、窄屏、横屏、桌面截图及控件边界。
- 验证多文稿新建/命名/切换/刷新、旧稿迁移、异步导入隔离、删除撤销与存储故障。
- 独立验证 PWA 注册/缓存、离线刷新和首次离线 DOCX 导入、安装能力、子目录部署与更新等待；普通 UI 导入拦截测试禁用 service worker，避免缓存绕过测试路由。
