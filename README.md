# Flow · 简易提词器

以手机为主的 Material Design 风格提词器。首页直接编辑文稿，文稿库可提前准备多篇讲稿，右上角齿轮打开提词设置。无需注册账号。

## 使用

1. 首次打开是空白文稿。填写标题并输入或粘贴正文，也可以点击导入图标，选择 UTF-8 的 TXT 或 Word 的 DOCX 文稿。
2. 点击右上角齿轮，调整字体、字号、颜色、滚动速度、倒计时、镜像、计时器和参考线。设置会自动保存。
3. 点击“开始提词”。轻点画面暂停或继续，上下拖动调整位置。
4. 提词底部直接显示速度和字号的加减按钮。字号每次调整 2 px，范围为 10–100 px，立即生效并保存；阅读进度、计时和暂停状态保持连续。
5. 点击关闭按钮返回文稿；重播按钮从头开始。窄屏上的控制按钮分两行显示。

## 文稿库与保存

点击“文稿库”新建、搜索或切换文稿；搜索支持标题和正文。首页标题可直接修改，最多 120 个字符。正文和标题自动保存，切换文稿时保留当前修改，下次打开恢复上次选择。

删除文稿后可在书库内点击“撤销删除”。撤销会恢复被删除的稿子，保留当前选择及刚写下的新内容。删除最后一篇后可继续在空白稿中编辑。清空正文和文件导入也支持撤销；导入失败、导入期间编辑或切换文稿，不会让迟到的导入结果覆盖新内容。

文稿通过 IndexedDB 保存在当前设备、当前浏览器的网站数据中，旧版保存的单篇正文会在首次升级时迁入文稿库。无需账号，没有云端同步。更换浏览器或设备不会自动带走稿件，清除网站数据会删除本地保存内容。需要长期备份时，请另存一份正文。

“已自动保存”表示本地保存已完成；若提示未能保存，当前会话仍可编辑和提词，请先复制正文到其他位置保留。

## 文件导入

- TXT：UTF-8 编码，文件不超过 1 MiB。
- DOCX：文件不超过 10 MiB，正文解压后不超过 8 MiB，导入文字不超过 100 万个 UTF-16 代码单元。
- DOCX 提取正文中的文字，保留段落、手动换行、制表符及表格内容。图片与文档样式不会导入。
- 旧版 DOC、加密文档、分卷 ZIP 和 ZIP64 目录请先在 Word 中另存为普通 DOCX。
- 文件在浏览器本地解析，不会上传。解压组件随项目提供，首次导入 DOCX 时按需执行；离线资源准备时会一并缓存。

## 安装与离线使用

通过 HTTPS 网站或 localhost 打开，并保持联网，直到设置中的离线状态显示“离线已准备好”。此后可离线打开应用、编辑和切换已保存文稿、提词，以及导入本地 TXT / DOCX，包括首次导入 DOCX。

支持安装提示的浏览器会在设置中显示“安装到设备”，也可使用浏览器菜单中的安装选项。iPhone 请在 Safari 中轻点“共享”，选择“添加到主屏幕”。离线资源与稿件仍保存在当前设备；浏览器清理网站数据后需要重新联网准备。

有新版本时，设置中会显示更新提示。应用不会在编辑或提词时自动刷新；结束后关闭所有提词器窗口，再重新打开即可更新。

## 快捷操作

| 操作 | 快捷键 |
| --- | --- |
| 暂停 / 继续 | 在提词画面按 Space 或 Enter |
| 调整文字位置 | ↑ / ↓，PageUp / PageDown |
| 调整滚动速度 | ← / → |
| 返回编辑 | Esc |

蓝牙手柄方向键控制位置与速度，A 键暂停 / 继续，B 键返回编辑。浏览器不支持原生全屏或保持屏幕常亮时，仍可正常使用页面内提词。

## 本地运行与验证

直接打开 `index.html` 可使用基本提词能力；安装和离线资源准备需要 HTTPS 或 localhost 网站环境。项目可直接作为静态网站部署，无需构建或安装网页运行依赖，资源路径兼容 GitHub Pages 子目录。

浏览器测试使用 Python 与 Playwright。从项目根目录运行：

```powershell
python -m http.server 4175 --bind 127.0.0.1
```

在另一个终端运行：

```powershell
python tests/verify_ui.py
python tests/verify_script_library.py
python tests/verify_pwa.py
python tests/capture_ui.py
$env:TELEPROMPTER_TEST_BROWSER = "webkit"
python tests/verify_ui.py
python tests/verify_script_library.py
python tests/capture_ui.py
```

首次使用测试工具需安装 Python 的 `playwright` 包及 Chromium、WebKit 浏览器。UI 与文稿存储测试可用 `TELEPROMPTER_TEST_URL` 指定服务地址。普通 UI 测试禁用 service worker，以确保 DOCX 加载失败等网络拦截用例可重复；PWA 测试使用独立的本地服务器和 Chromium 验证真实离线行为。截图覆盖空白首页、已填充书库和不同屏幕尺寸的阅读器，结果位于被 Git 忽略的 `tests/artifacts/`。
